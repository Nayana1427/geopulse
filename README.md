# 🌍 GeoPulse

### Environmental Intelligence Platform

GeoPulse is an interactive web-based environmental intelligence dashboard that enables users to explore locations worldwide through an interactive map while viewing weather insights, climate indicators, and environmental monitoring data.

---

## 🚀 Features

- 🌎 Interactive world map powered by Leaflet
- 🔍 Search any city or country worldwide
- 🌡 Real-time weather information
- 💨 Wind speed and humidity monitoring
- 🌫 Air quality status dashboard
- ⚠ Climate risk assessment
- 📍 Automatic location detection
- 📱 Responsive modern UI

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Leaflet.js
- OpenStreetMap
- Open-Meteo API
